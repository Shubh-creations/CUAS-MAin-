# Pretrained Deep Learning Weights

This directory houses pretrained and fine-tuned weights for CUAS detection and classification.

- `yolov8n.pt`: Ultralytics YOLOv8 nano model (automatically downloaded if YOLO backend is used).
- `fasterrcnn_resnet50_fpn.pth`: PyTorch model checkpoint.
- `drone_classifier.pth`: Custom weights for the 5-class drone classifier.
